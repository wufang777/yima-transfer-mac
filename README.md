# 易码互传 · macOS 原生版

> 局域网文件互传工具 —— 手机扫码即传，电脑 ↔ 电脑直连，无需安装任何手机 App。
> macOS 原生壳层：菜单栏常驻（rumps）+ 网页控制台。

**当前版本：v1.6.2** ｜ 开发：易码通科技

---

## 这是什么

易码互传解决一个很具体的痛点：**手机和 Mac 之间传文件太麻烦**——微信压缩图片、AirDrop 又挑设备和网络。

它在你 Mac 上跑一个轻量局域网服务，手机连同一个 WiFi 用浏览器扫码打开网页，就能双向传文件。
手机端**零安装**，传完即走。

## 功能

### 手机 ↔ 电脑

| 功能 | 说明 |
|------|------|
| 扫码连接 | 手机相机 / 微信扫二维码直接打开传输页，无需输入地址 |
| 上传到电脑 | 点选或拖拽文件，带实时进度条，可多选批量传 |
| 下载到手机 | 手机页直接下载电脑上的文件 |
| **打开 / 复制** | 图片、PDF、文本可在手机浏览器**直接预览**（不占手机存储）；也可**一键复制链接**发给微信好友 |
| 电脑主动分享 | 控制台弹出系统原生选文件窗口，选中的文件出现在手机端「电脑发来的文件」区 |

### 电脑控制台（仅本机可访问）

- **连接状态**：局域网地址、二维码、当前保存目录
- **文件管理**：已接收文件列表，可下载 / 在 Finder 中显示 / 删除 / **发给手机**
- **发送文件到手机**：系统原生多选文件 → 分享列表 → 手机端下载，用完可取消分享
- **设备发现**：UDP 广播自动发现同网段的其它易码互传；广播被防火墙拦时，用 HTTP 扫描（并发探测各网段）兜底，也可手动填 IP 添加
- **电脑 ↔ 电脑发文件**：控制台直接选中设备投送，由本机服务端转发到对方（绕开浏览器跨域限制，失败时会给出具体原因：对方未运行 / 防火墙拦截 / 主机不可达）
- **版本与更新**：检查更新 → 下载 → 一键升级（含校验与回滚）

### 其它

| 功能 | 说明 |
|------|------|
| **微信接收目录** | 一键把接收目录设为微信的文件目录，手机传来的文件与微信收到的文件放在一起（自动探测本机微信账号，支持多账号切换） |
| 菜单栏常驻 | 显示二维码 / 打开控制台 / 打开接收目录 / 复制地址 / 设置 / 检查更新 / 重启 / 退出 |
| 系统通知 | 收到文件弹 macOS 通知，也可配置为自动打开接收目录 |
| 开机自启 | LaunchAgents 实现，设置页一键开关 |
| 在线升级 | 内置升级引擎：拉取清单 → 校验 sha256 → 挂载 dmg 替换 → 签名校验，失败自动回滚 |

## 快速开始

### 使用打包好的版本

1. 下载 `yima-transfer-<版本>-<构建号>.dmg`，双击挂载
2. 把「易码互传」拖入「应用程序」
3. 首次打开：右键 →「打开」→ 再点「打开」（未做公证签名，需手动放行一次）
   ```bash
   xattr -cr /Applications/易码互传.app    # 或直接用这行解除隔离
   ```
4. 首次运行会请求两个权限：
   - **本地网络**（不授权会导致设备发现列表为空）
   - 通知权限（不想要可在设置页关闭）
5. 启动后自动打开控制台 `http://localhost:8000/console`

### 从源码运行（调试）

```bash
pip3 install rumps segno Pillow pyobjc-framework-Cocoa

python3 app.py                  # 菜单栏模式（自动开控制台）
python3 app.py --console        # 终端模式，二维码打印在终端，Ctrl+C 退出
python3 app.py --no-open        # 菜单栏模式但不自动开浏览器
python3 app.py --version        # 打印版本号
```

## 构建与发布

```bash
bash build_mac.sh                       # 出 dist/易码互传.app + dist/易码互传.dmg
bash release.sh 1.4.0 "更新说明…"        # 改版本号 → 构建 → 出包 → 生成 version.json
bash release.sh --build-only --notes "…" # 只重建，不动版本号
```

`release.sh` 产出两个上线文件：`yima-transfer-<版本>-<构建号>.dmg` 与 `version.json`
（含 sha256 / 大小 / 更新说明）。把两者放到任意 HTTP 静态目录，客户端在「设置 → 在线升级」填入清单地址即可收到更新。

### 打包踩坑（重打包报错先看这里）

1. **必须在非沙箱环境运行**：PyInstaller 对产物执行 `codesign --remove`，受限沙箱会报 `Operation not permitted`
2. **dmg 生成需可写 `/Volumes`**：`hdiutil create` 会内部挂载临时镜像再写入，被拦会报 `操作不被允许`
3. **先清残留**：上次打包留下的已签名二进制会让重签失败；脚本已内置清理
4. **.app 被占用**：先退出正在运行的实例，否则替换会提示「正在使用中」
5. **同名旧卷挂载**：`hdiutil info | grep 易码` 检查，先 detach 再重试

> 脚本已内置**成品自检**：挂载 dmg 后比对二进制版本号 + sha256，不一致直接中止发布（防止把旧包当新版发出去）。

更多细节见 [`MAC_BUILD_README.md`](MAC_BUILD_README.md)。

## 技术架构

```
app.py                 单文件主程序（约 1800 行）
├── 品牌/版本常量        APP_VERSION_NUM / APP_BUILD / APP_CHANNEL
├── 配置层               ~/Library/Application Support/易码互传/config.json
├── 网络核心             ThreadingHTTPServer + UDP 58887 发现（协议与 Windows 版一致）
├── 升级引擎             清单校验 → 下载 → 挂载替换 → 签名校验 → 回滚
└── 壳层                 rumps 菜单栏 / 系统通知 / LaunchAgents

console.html           电脑端控制台（仅本机）
index.html             手机端页面
settings.html          设置页
build_mac.sh           PyInstaller 打包 + dmg 生成 + 成品自检
release.sh             版本号管理 + 发布流水线
version.sample.json    更新清单格式样例
```

**关键设计**

- **上传协议**：原始 body + `?name=<urlencoded>`，不用 multipart（与 Windows 版保持一致）
- **本机鉴权**：`/api/local/*` 与 `/api/share` 只放行回环与本机网卡地址，其它设备 403；
  防止同网段设备借道读取电脑私有文件
- **无内网穿透**：纯局域网，文件不经任何第三方服务器
- **预览与下载分离**：`?inline=1` 返回真实 MIME 走浏览器预览，不带参数则强制下载
